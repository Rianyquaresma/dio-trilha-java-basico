# dio-trilha-java-basico

Repositório para exemplos do curso de **Java Básico** pela [DIO (Digital Innovation One)](https://www.dio.me/).

## Sobre o Projeto

Este repositório contém códigos, exercícios e exemplos desenvolvidos durante o curso de Java Básico pela DIO. O objetivo é fornecer uma base sólida sobre os principais conceitos da linguagem Java para iniciantes.

## Estrutura do Projeto

- [`SmartTv.java`](./SmartTv.java): Exemplo de implementação de uma Smart TV em Java.
- [`Usuario.java`](./Usuario.java): Exemplo de interação de usuário com a Smart TV.
- [`tipos-variaveis/`](./tipos-variaveis): Exercícios e exemplos sobre tipos e variáveis em Java.
- [`settings.json`](./settings.json): Configuração do projeto para o VS Code.
- [`.gitignore`](./.gitignore): Arquivos e pastas ignorados pelo Git.

## Pré-requisitos

- [Java JDK 8+](https://www.oracle.com/java/technologies/javase-downloads.html)
- [Visual Studio Code](https://code.visualstudio.com/) (opcional, mas recomendado)
- Extensão Java para VS Code: [Guide](https://code.visualstudio.com/docs/languages/java)

## Como Executar

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/Rianyquaresma/dio-trilha-java-basico.git
   cd dio-trilha-java-basico
   ```

2. **Compile e execute os arquivos Java:**
   ```bash
   javac SmartTv.java Usuario.java
   java Usuario
   ```

   > Os arquivos podem ser executados individualmente conforme o exemplo acima.

3. **Utilizando o VS Code:**
   - Abra a pasta do projeto no VS Code.
   - Use a aba "JAVA PROJECTS" para compilar e executar os arquivos.
